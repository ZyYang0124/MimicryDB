# MimicryDB data dictionary

This document describes the fields of the current schema (`supabase/migrations/001_initial.sql`). Future migrations (002+) extend it per `docs/ROADMAP.md`; this dictionary is updated with each schema change.

## Conventions

- All tables use `uuid` primary keys generated by `gen_random_uuid()`; `timestamptz` timestamps default to `now()`.
- Public identifiers are stable and never reused: interactions use `MIMICRY:NNNNNN`, evolutionary origins use `ORIGIN:NNNNNN`.
- `NULL` means *not recorded*. Curators must not invent values to satisfy constraints; where a scientific distinction between *unknown*, *not reported* and *not applicable* matters, it is expressed through status fields rather than free text.

## taxon

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | uuid | Internal identifier |
| `scientific_name` | text | Full scientific name as used by the database (required) |
| `canonical_name` | text | Name without authorship/year |
| `name_verbatim` | text | Name exactly as it appears in the source publication (required) |
| `rank` | text | Taxonomic rank (species, genus, family, …, or unresolved) |
| `kingdom` | text | Kingdom of the taxon |
| `parent_taxon_id` | uuid → taxon | Parent in the stored hierarchy |
| `taxonomic_status` | text | `accepted` (default) or other controlled status (synonym, doubtful, …) |
| `created_at` / `updated_at` | timestamptz | Record timestamps |

Planned in migration 002: `accepted_name`, `authorship`, phylum→genus hierarchy columns, `external_source` + `external_taxon_id`, `taxonomic_resolution`, `notes`, and a `taxon_synonym` table.

## reference

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | uuid | Internal identifier |
| `doi` | text | Digital Object Identifier when available |
| `title` | text | Publication title (required) |
| `authors` / `year` / `journal` | text / int / text | Citation fields |
| `url` | text | Stable link |
| `citation_text` | text | Full citation string |
| `created_at` | timestamptz | Record timestamp |

Planned in migration 002: `pmid`, `volume`, `issue`, `pages`, `abstract`, `reference_type`, `notes`.

## mimicry_interaction

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | uuid | Internal identifier |
| `public_id` | text (unique) | Stable public ID `MIMICRY:NNNNNN` |
| `mimic_taxon_id` | uuid → taxon | Organism producing the mimetic signal |
| `model_taxon_id` | uuid → taxon | Organism/signal being imitated |
| `receiver_description` | text | Receiver class or species; free description when unresolved |
| `interaction_status` | text | Workflow state: `candidate` (default) → `draft` → `needs_review` → `reviewed` → `published`; plus `rejected`, `disputed`, `withdrawn`. Only `published` rows are publicly readable (RLS) |
| `knowledge_status` | text | Scientific status: `reported` (default) / `supported` / `inferred` — deliberately separate from workflow state |
| `evidence_grade` | text | `E0`–`E4` per `docs/EVIDENCE_GUIDELINES.md`, default `E0` |
| `evidence_grade_reason` | text | Curator justification for the grade |
| `mimicry_summary` | text | One-paragraph scientific summary |
| `model_resolution` | text | Resolution at which the model is identified (species … higher taxon, functional class, unknown) |
| `confidence` | numeric | Curator confidence |
| `created_at` / `updated_at` | timestamptz | Record timestamps |

Planned in migration 002: `mimic_entity_id`, `model_entity_id`, `receiver_taxon_id`, `receiver_resolution`, `specific_model_identified`, `geographic_overlap_status`, `curator_notes`, `created_by`, `reviewed_by`, `reviewed_at`, `published_at`.

## evidence

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | uuid | Internal identifier |
| `interaction_id` | uuid → mimicry_interaction | The claim being supported (required) |
| `reference_id` | uuid → reference | Source publication (required) |
| `evidence_text` | text | Exact or paraphrased passage (required) |
| `page` / `section` / `figure` | text | Locators inside the source |
| `evidence_grade` | text | Grade of this specific piece of evidence |
| `source_method` | text | `manual` (default) / `LLM extraction` / `imported review` / `external database` / `other` — LLM-extracted evidence never enters publication automatically (see `docs/LLM_EXTRACTION_POLICY.md`) |
| `created_at` | timestamptz | Record timestamp |

## audit_log

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | uuid | Internal identifier |
| `entity_type` / `entity_id` | text / uuid | What changed |
| `action` | text | `create` / `update` / `status_change` / `publish` / `reject` / `withdraw` / … |
| `old_value` / `new_value` | jsonb | Before/after snapshot; the previous state never disappears silently |
| `changed_by` | uuid | Acting account |
| `reason` | text | Why the change was made |
| `timestamp` | timestamptz | When it happened |
